# Consensus Engine

The consensus engine combines successful agent forecasts into one probability.

- Agent probabilities are weighted by confidence and stored reputation.
- Low confidence and strong disagreement reduce consensus confidence.
- The reasoning trace records participating agents and aggregation steps.
- Missing or failed agents are excluded rather than replaced with fabricated output.
- Reputation can be updated after a market resolves.

Consensus is an analytical estimate, not financial advice or a guarantee of an outcome.
